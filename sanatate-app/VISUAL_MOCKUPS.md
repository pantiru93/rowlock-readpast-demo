## Color Coding

### Status Indicators
- 🟦 Blue (#1F7A8C) - Primary actions, active states
- 🟩 Green (#66BB6A) - Success, taken doses
- 🟧 Orange (#FF9800) - Warning, expiring soon
- 🟥 Red (#F44336) - Error, expired, low stock

### Component Styles
- **Cards**: White (#FFFFFF) with shadow
- **Background**: Light gray (#F5F7FA)
- **Text**: Dark gray (#222222) primary, #666666 secondary
- **Buttons**: Blue with white text
- **Chips**: Colored background with white text

## Interactive Elements

- ✓ Checkmarks indicate completed actions
- → Arrows indicate navigation forward
- ← Back arrow for returning to previous screen
- + FAB and header buttons for adding items
- 🔍 Search functionality where applicable
- Toggle switches for settings
